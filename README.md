## ภาษาไทย

โปรเจกต์นี้เป็นส่วนหนึ่งของการศึกษารายวิชา **Design and Analysis of Algorithm (รหัสวิชา 040613206)** ของ **ภาควิชาวิทยาการคอมพิวเตอร์และสารสนเทศ คณะวิทยาศาสตร์ประยุกต์ มหาวิทยาลัยเทคโนโลยีพระจอมเกล้าพระนครเหนือ (KMUTNB)**

### รายละเอียดของโปรเจกต์

เนื้อหาภายในโปรเจกต์นี้ประกอบไปด้วย:

* **โจทย์จาก Grader**: โค้ดสำหรับการแก้โจทย์ปัญหาต่างๆ ที่ได้รับมอบหมายในระบบ Grader ของรายวิชา
* **ควิซ (Quiz)**: แนวทางการแก้ปัญหาและโค้ดสำหรับควิซในแต่ละส่วนของการเรียน
* **การศึกษาส่วนตัว**: โค้ดและอัลกอริทึมที่พัฒนาขึ้นเพิ่มเติมเพื่อทำความเข้าใจเนื้อหาบทเรียนและการฝึกฝนส่วนตัว

### โครงสร้างและการจัดเก็บ

โฟลเดอร์ต่างๆ ภายในโปรเจกต์นี้ถูกแบ่งออกตามหัวข้อการเรียนรู้หรือประเภทของงานที่ได้รับมอบหมาย เช่น แนวคิดการเขียนโปรแกรมแบบพลวัต (Dynamic Programming), อัลกอริทึมแบบละโมบ (Greedy Algorithm), กราฟ (Graph) และส่วนของแล็บปฏิบัติการต่างๆ

### หมายเหตุ

โค้ดและแนวทางทั้งหมดในโปรเจกต์นี้ถูกจัดทำและรวบรวมขึ้นเพื่อจุดประสงค์ทางการศึกษา การฝึกฝน และการทบทวนเนื้อหาส่วนตัวเท่านั้น

## English

This repository is part of the **Design and Analysis of Algorithm (040613206)** course at the **Department of Computer and Information Science, Faculty of Applied Science, King Mongkut's University of Technology North Bangkok (KMUTNB)**.

### Project Overview

The purpose of this project is to collect various programming assignments, quiz solutions, and personal study materials related to algorithm design and analysis. The contents include:

* **Grader Problems**: Source code for solving algorithmic problems assigned in the course's automated grader system.
* **Quizzes**: Solutions and source code for various quizzes completed during the course.
* **Personal Study**: Additional code and algorithms developed for self-study and a deeper understanding of the course materials.

### Structure

The directories within this project are organized by learning topics and assignment types, such as Dynamic Programming, Greedy Algorithm, Graph, and various laboratory sessions.

### Note

All code and materials in this repository are created and collected strictly for educational purposes, personal practice, and academic review.
